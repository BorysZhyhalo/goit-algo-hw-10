# Домашнє завдання — Метод Монте-Карло

## Опис

Обчислення визначеного інтеграла функції `f(x) = x²` на інтервалі `[0, 2]` методом Монте-Карло (алгоритм «попадання/промаху») та порівняння результату з аналітичним розрахунком і функцією `scipy.integrate.quad`.

## Файли

| Файл | Призначення |
|------|-------------|
| `view.py` | Визначення функції, меж інтегрування та візуалізація графіка з сірою зоною під кривою |
| `quad.py` | Реалізація методу Монте-Карло та порівняльний аналіз результатів |

## Запуск

```bash
cd monte_carlo
python quad.py
python view.py
```

## Постановка задачі

Обчислити площу під графіком функції

**Аналітичне рішення:**

\[
\int x^2 \, dx = \frac{x^3}{3} \Big|_0^2 = \frac{8}{3} \approx 2{,}666667
\]

## Алгоритм Монте-Карло

1. Обмежити область прямокутником: `x ∈ [0, 2]`, `y ∈ [0, 4]` (бо `max f(x) = f(2) = 4`).
2. Згенерувати `N` випадкових точок `(x, y)` у цьому прямокутнику.
3. Порахувати точки, де `y < f(x)` — вони лежать під кривою.
4. Оцінити інтеграл:

\[
S \approx (b - a) \cdot f(b) \cdot \frac{N_{\text{під кривою}}}{N}
\]

## Результати порівняння

Приклад запуску `quad.py` з `N = 1 000 000` точок:

| Метод | Значення | Примітка |
|-------|----------|----------|
| Аналітичний | 2.6666666667 | Точне значення `8/3` |
| SciPy `quad` | 2.6666666667 | Похибка оцінки ~10⁻¹³ |
| Монте-Карло | ~2.66–2.68 | Залежить від випадкової вибірки |

Типова відносна похибка методу Монте-Карло при мільйоні точок — **менше 0.5%**.

## Висновки

1. **Метод Монте-Карло працює коректно.** Отримане значення інтеграла збігається з аналітичним (`8/3`) та результатом `scipy.integrate.quad` з високою точністю.

2. **Метод є ймовірнісним.** Кожен запуск дає трохи інший результат через випадкову генерацію точок, але при збільшенні `N` оцінка стабільно наближається до точного значення.

3. **Точність залежить від кількості точок.** Чим більше випадкових точок, тим менша статистична похибка. При `N = 1 000 000` похибка зазвичай не перевищує кількох десятих відсотка.

4. **SciPy `quad` дає найточніший детермінований результат** для гладких функцій, тоді як Монте-Карло корисний для складних або багатовимірних інтегралів, де аналітичне або числове інтегрування ускладнене.

5. **Візуалізація в `view.py` підтверджує геометричний зміст задачі** — сіра зона під кривою `f(x) = x²` на `[0, 2]` відповідає шуканій площі, яку оцінює алгоритм Монте-Карло.
